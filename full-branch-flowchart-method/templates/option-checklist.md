> 用途：会上逐条让客户勾选 —— **把"问答"变成"选择"**
> 对应流程图上的【橙虚线菱形】编号，三处一一对应（图 / 本清单 / 需求文档）

---

## 使用说明

```
1. 每条 = 一道选择题：A / B（可加 C）
2. ⭐ 必须给"我方建议"—— 客户要的是引导，不是甩一堆选项
3. 会上客户勾选 → 当场改图（橙虚线转实线 或 剪掉）
4. 客户说"不确定" → 标 ⏳待定 + 责任人和期限
```
