# Practice · Knowledge · Feedback ｜ 实践·知识·反馈

> **知识让你「知道」，实践让你「会做」，反馈让你「做对」。**
> 三者相乘，缺一为零。

---

## 项目简介

**为什么学了很多却做不出来？为什么做了很久却原地踏步？**

这个 Skill 提供一个可操作的答案框架：

它把「学习与成长」这件事拆成三个可独立检查的变量——**知识（Knowledge）、实践（Practice）、反馈（Feedback）**——并证明一个反直觉的结论：**三者是乘法关系，而不是加法关系**。任何一项为 0，能力就是 0。

在此基础上，它整合了三个被反复验证的经典学习理论（隐性知识、技能获得五阶段、知识转化螺旋），给出一套完整的**诊断 → 处方 → 记录 → 复盘**工具链。

适用对象：跨领域学习者、职场新人、带新人的师傅、以及任何想弄清「经验到底怎么积累」的人。

## 核心思想

```
        能力 = 知识 × 实践 × 反馈
                ↑      ↑      ↑
              看来的  做来的  修正来的
```

**四种典型失衡**：

| 状态 | 症状 | 结果 |
|------|------|------|
| 只有知识 | 懂很多道理，下手就慌 | 纸上谈兵 |
| 只有实践 | 干了很多年，还是老样子 | 低水平重复 |
| 知识 + 实践，无反馈 | 把错误动作练成了习惯 | 错误固化 |
| 三者齐全 | 每一轮都比上一轮强一点 | **能力复利** |

**顺序洞察**：跨领域新人正确的路径不是「学完再做」，而是
**先跟做 → 带着问题补知识 → 主动要反馈**。
（「学完再上」这条路，往往永远开始不了。）

## 方法流程

```
① 诊断 —— 用「能力诊断表」五问，找出自己断在哪一环
          （最高频的断点是"反馈"，大多数人的努力卡在这里）

② 定位 —— 用 Dreyfus 五阶段模型判断自己的当前层级
          （决定该"学"还是该"练"）

③ 处方 —— 按断点对症下药：
          知识缺 → 补框架    实践缺 → 下场做
          反馈缺 → 主动要    外化缺 → 写复盘
          刻意练习缺 → 挑能力边缘的任务

④ 记录 —— 用「实践日志」每天 5 分钟记录六问
          日 → 周（抽象方法）→ 月（自评阶段）

⑤ 外化 —— 把隐性经验写成显性文字，沉淀为可复用的方法
          （这是"经历"变成"经验"的唯一通道）
```

## 理论根基

| 理论 | 提出者 | 本框架中的作用 |
|------|--------|--------------|
| **隐性知识** Tacit Knowledge | Michael Polanyi (1966) | 解释为什么有些能力"看书学不会"，必须跟人做 |
| **技能获得五阶段** | Dreyfus 兄弟 (1986) | 提供能力定位标尺；说明知识只能带到第 2 阶段 |
| **SECI 知识转化螺旋** | 野中郁次郎 (1995) | 提供"外化/组合/内化/社会化"四种转化动作 |
| **刻意练习** Deliberate Practice | Anders Ericsson (2016) | 说明"做得多"≠"练得对"，关键在于能力边缘 + 即时反馈 |
| **学习留存率** 学习金字塔 | 美国国家训练实验室 | 佐证：讨论/实践/教别人的留存率远高于阅读听讲 |
| **心流 / 能力边缘** | Mihaly Csikszentmihalyi (1990) | 解释"刚好不会"的任务为什么学习效率最高 |

## 应用场景

```
· 跨领域新人设计前 90 天学习路径
· 职场人自查"为什么努力没有回报"
· 师傅/带教设计"带人"流程（先框架 → 让做 → 立刻反馈）
· 建立个人复盘系统（日志 / 周复盘 / 月度能力自评）
· 判断某项新能力该"自学"还是"找人带"
```

## 使用方式

### 作为 AI Agent Skill 安装

```bash
# 方式 1：克隆到技能目录
git clone https://github.com/<owner>/<repo>.git
cp -r <repo>/practice-knowledge-feedback ~/.hermes/skills/productivity/

# 方式 2：直接复制 SKILL.md 与 templates/ 到你的技能目录
```

目录结构：

```
practice-knowledge-feedback/
├── SKILL.md                    # 主文件（十二节）
└── templates/
    └── practice-log.md         # 实践日志（日/周/月三层）
```

### 作为方法论直接使用（无需 AI）

直接读 `SKILL.md` 的：
- **第二节**（核心模型）→ 理解乘法关系
- **第六节**（能力诊断表）→ 找出自己的断点
- **第七节**（实践日志）→ 开始记录
