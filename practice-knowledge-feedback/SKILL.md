# Practice · Knowledge · Feedback（PKF Loop）

> **一句话**：知识让你「知道」，实践让你「会做」，反馈让你「做对」。
> 三者的乘积决定能力——任何一项为 0，结果就是 0。

---

## 一、何时使用

- 需要为**新人 / 跨领域者**设计学习路径
- 用户困惑：**学了很多却做不出来** / 做了很久却没长进
- 讨论「经验」「能力」「悟性」「刻意练习」这类话题
- 需要建立**复盘机制**或个人成长记录系统
- 判断某项能力**能否自学**

---

## 二、⭐ 核心模型

```
        能力 = 知识 × 实践 × 反馈
                ↑      ↑      ↑
              看来的  做来的  修正来的

⚠️ 相乘关系 —— 任一项为 0，结果为 0

· 只有知识         → 纸上谈兵（懂很多，干不了）
· 只有实践         → 低水平重复（干很久，没长进）
· 知识 + 实践无反馈 → 错误固化（把错的练熟了）
· 三者齐全         → 能力复利增长
```

**顺序洞察**：
跨领域新人应走 **实践 →（带着问题补）知识 →（主动要）反馈**，
而不是「学完再做」——后者往往永远开始不了。

---

## 三、实践 vs 知识：七个维度

| 维度 | 知识 | 实践 |
|------|------|------|
| 形态 | 显性 · 可编码 | 隐性 · 难编码（手感/直觉） |
| 获得 | 阅读 · 听课 · 背诵 | 动手 · 试错 · 重复 |
| 载体 | 书 / 文档 / 大脑 | 身体 / 情境 / 现场 |
| 验证 | 逻辑自洽即可 | 必须结果有效 |
| 迁移 | 高（易传播） | 低（绑情境，换场景要重学） |
| 时间 | 可瞬间获取 | 必须累积（不可压缩） |
| 犯错成本 | 低 | 高（现场有代价） |

**三个关键洞察**：
```
① 知识 = 别人实践的「压缩包」
   → 能快速解压（几小时吸收别人多年经验）
   → ⚠️ 但会失真（脱离当时的条件、约束与例外）

② 实践 = 知识的「解压 + 验证」过程
   → 慢，但真实（你会遇到所有"例外情况"）

③ 二者不是对立，是同一物的两种形态
   → 知识是地图，实践是走路
   → 只看地图不走：永远到不了
   → 只走不看地图：绕远且不知为何
```

## 四、⭐ 三个经典理论（用于定位）

### ① Polanyi · 隐性知识（Tacit Knowledge）
```
命题："我们知道的，比我们能说出来的多"
例：会骑车 ≠ 能写出骑车的物理公式

启示：
· 隐性成分高的能力（判断力/沟通/手艺/带团队）→ 必须【跟人做 + 观察 + 模仿】
· 显性成分高的能力（工具操作/法规条款）→ 可自学速成
用法：拿到一项能力先问——"这件事能写全吗？" 写不全 → 找师傅、下场做
```

### ② Dreyfus · 技能获得五阶段
```
1 新手（Novice）           靠规则（"手册说这么做"）
2 高级新手（Adv. Beginner） 靠经验（"上次类似情况是…"）
3 胜任者（Competent）       能规划（"我判断该这么做"，会取舍）
4 精通者（Proficient）      直觉判断（"一眼看出问题在哪"）
5 专家（Expert）            无需思考（"就这么做"）

⭐ 核心洞察：知识能带你到 1–2 阶段，3 阶段之后全靠实践。
用法：定位阶段 → 决定该「学」还是该「练」
     1-2 阶段：补知识 + 多跟做
     3+ 阶段：刻意练习（练不会的）+ 主动要反馈
```

### ③ 野中郁次郎 · SECI 知识转化螺旋
```
隐性 → 显性　外化 (Externalization)：把感觉/经验写下来 ⭐ 最难也最增值
显性 → 显性　组合 (Combination)：整理成体系、模板、SOP
显性 → 隐性　内化 (Internalization)：练成肌肉记忆
隐性 → 隐性　社会化 (Socialization)：师带徒、看中学

用法映射：
· 跟师傅/前辈学 = 社会化（隐性→隐性）
· 每天写复盘   = 外化（隐性→显性）⭐ 把"经历"变成"经验"
· 整理模板/SOP = 组合（显性→显性）
· 反复练到不用想 = 内化（显性→隐性）
```

## 五、⭐ 让知识指导实践的 6 条方法

```
① 落地成动作 —— 知识不能变成动作 = 没学
   ❌"要理解客户业务"
   ✅"每天记 3 条业务规则，周末整理成流程图"

② ⭐ 带着问题学，不要学完再做
   常见错误：想"先学完再上" → 永远上不了
   正解：先跟着做 → 遇到不懂 → 立刻针对性查/问
   （问题驱动的学习，留存率远高于被动阅读）

③ ⭐ 用输出倒逼输入（费曼技巧）
   学完必须产出：文档 / 流程图 / 给同事讲一遍
   讲不出来 = 没学会（最诚实的检验）

④ ⭐⭐ 建立反馈闭环（把知识变能力的关键）
   做 → 看结果 → 修正理解 → 再做
   ⚠️ 无反馈的实践 = 重复（"10 年经验"可能只是 1 年重复 10 次）
   → 主动要反馈，不要等（没人会主动告诉你哪里错了）

⑤ ⭐ 把实践知识化（外化 · 积累经验）
   每次做完问三问：
   · 我当时怎么判断的？
   · 依据是什么？
   · 下次会怎么改？
   → 写下来 = 经验（而不是"经历"）

⑥ 刻意练习（Ericsson）
   不是"做得多"，而是在【能力边缘】做 + 即时反馈 + 修正
   → 做你刚好不会的，而不是重复你已经会的
```

## 六、⭐ 能力诊断表（自评工具）

对照下面五问，找出自己断在哪一环：

| # | 自问 | 若答案是「否」→ 你的短板 | 处方 |
|:-:|------|----------------------|------|
| 1 | 我知道该做什么、为什么做吗？ | 知识缺 | 先补框架与原理 |
| 2 | 我最近真的动手做过吗？ | 实践缺 | 找机会下场，别只看 |
| 3 | 有人告诉我"哪里做错了"吗？ | 反馈缺 ⭐ 最常见 | 主动找高手要反馈 |
| 4 | 我把做过的总结成文字了吗？ | 外化缺 | 写复盘 / 建案例库 |
| 5 | 我在练"不会的"还是重复"会的"？ | 刻意练习缺 | 挑能力边缘的任务 |

```
⭐ 高频断点：③ 反馈 —— 大多数人的"努力"卡在这里。
   表现为：很忙、很累、做了很多，但能力原地踏步。
```

## 七、📋 实践日志（每天 5 分钟的核心工具）

见 `templates/practice-log.md`（含日 / 周 / 月三个层级）。

```
## YYYY-MM-DD ｜ 场景：____

① 今天我做了什么（客观事实）
② 我当时的判断 / 做法（+ 依据是什么）
③ 结果如何（完全正确 / 部分正确 / 错了）
④ 反馈来自谁（师傅 / 同事 / 客户 / 结果数据）
⑤ 修正后的理解（一句话）
⑥ 下次怎么做（具体动作）

⭐ 每周五抽象出 1 条"我的方法"（外化）
⭐ 每月自评一次技能阶段（Dreyfus）
```

## 八、应用场景

```
【跨领域新人】
· 定位：Dreyfus 阶段 1 → 先跟做、多记录、少下结论
· 动作：实践日志 + 每周要反馈 + 用输出倒逼学习
· 禁忌：想"学完再上"

【有经验但卡住的人】
· 诊断：是否只有"实践"没有"反馈"（低水平重复）？
· 动作：找高手要反馈 + 刻意练习（练不会的）+ 外化沉淀

【带新人 / 教学】
· 顺序：先给框架（知识）→ 让他做（实践）→ 立刻给反馈（关键）
· 别只讲不练：隐性知识只能靠"社会化"传递（示范 + 一起做）

【判断某项能力能否自学】
· 隐性成分高（销售/谈判/管理/手艺）→ 必须找师傅 + 下场
· 显性成分高（软件操作/法规条款/流程规则）→ 可自学速成
```

## 九、⚠️ 六个常见坑

```
① 把"收藏/读完"当成"学会" —— 没有输出，等于没学
② 想"准备好再开始" —— 实践永远等不来"准备好"的那天
③ 只做不复盘 —— 经历不会自动变成经验
④ 只想要正面反馈 —— 真正的成长来自"哪里做错了"
⑤ 反馈来源质量低 —— 跟水平一般的人要反馈，会把错的固化
⑥ 把知识当终点 —— 知识只是地图，走路才是目的
```

## 十、如何主动要反馈（实操话术）

```
很多人不是不想反馈，而是不知道怎么开口。三句话模板：

① 定向提问（别问"我做得怎么样"）
   "我今天记的这份纪要，您看信息有没有漏？哪些不该记？"
   → 具体到一件事，对方好回答

② 提供自评再求校正
   "我自己复盘觉得 XX 处理得不对，您觉得呢？"
   → 显示你在思考，对方更愿意教

③ 定期要一次"方向反馈"（每周/每两周）
   "这两周我在学 XX，您觉得我的重点对不对？有没有更该先学的？"
   → 防止努力错方向（最贵的浪费）
```

## 十二、一句话总结

```
⭐ 知识让你「知道」，实践让你「会做」，反馈让你「做对」。

三者相乘，缺一为零；顺序上先跟做、带着问题补知识、主动要反馈。
最终目标：把「经历」变成「经验」，把「经验」变成「能力」。
```
