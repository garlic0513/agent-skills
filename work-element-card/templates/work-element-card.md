## 自查清单（填完过一遍）

```
□ 触发条件写的是"事件"，而不是模糊词（如"需要时"）？
□ 执行人员写的是【岗位】而不是具体人名？
□ 依据标准写了【文号 + 版本】吗？
□ 输入信息三类都考虑了吗（实物/单据/数据）？
□ 具体操作是"动作+对象+标准"三段式吗？
□ 输出结果区分了实物/系统/中间态吗？
□ 记录留痕写了【留什么·留哪里·谁签字】吗？
□ 异常情况每条都配了【处理方式 + 处理人】吗？
□ 时限频次写了数字吗（而不是"及时"）？
```
