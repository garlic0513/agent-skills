# 流程图质量五维打分卡（自评 / 互评 / 交付前体检）

> 用途：每张图交付前给自己打分；或接到「这张图怎么样」的问题时，别只说"看着还行"，用分数说话。
> 定稿：2026-10-26（用户要求纳入技能）

## 一、五维打分（每维 0–2 分，满分 10）

| 维度 | 2 分（合格线） | 1 分（要改） | 0 分（重画） |
|---|---|---|---|
| **① 正确性** | 现场同事认可"我们就是这么干的" | 有 1–2 个节点动作/角色归属可疑 | 画成产品功能流（点菜单/填框），业务说不通 |
| **② 完整性** | 每条异常分叉都有终点，无悬空箭头 | 缺 1–2 条异常路径 | 只有主流程，异常/退回全无 |
| **③ 可读性** | 新人拿图能照着独立做完 | 需口头解释才懂（线交叉、文字溢出） | 一页塞 40+ 节点导致糊成一团 |
| **④ 规范性** | 配色/编号/泳道/图例全符合模板 | 1–2 处偏离（如自创颜色） | 自创图例、判定画成矩形、编号乱 |
| **⑤ 可维护性** | 加一步不用重画、编号步长可插 | 加一步要改一串编号 | 连号编号、坐标手写硬编码 |

**分数解读**

```
10  = 教科书级（少见）
8–9 = 可评审、可进蓝图正文   ← 交付目标
7   = 合格（内部推演够用）
5–6 = 需要一轮修改
≤4  = 重画
```

## 二、快速自检 12 条（不打分时用这个，每条 ✔/✘）

```
□ ① 每个节点只有一个动作（没有"扫码并核对并提交"）
□ ② 每个判定只有两个出口，且都标了 是/否
□ ③ 每条分叉都有终点（无悬空箭头、无死循环）
□ ④ 每个节点有明确的角色泳道（不出现"无人认领"的动作）
□ ⑤ 配色只表达三件事：人工(白)/系统(蓝)/线下(灰)
□ ⑥ 编号步长一致（10/5），无断号无重号
□ ⑦ 系统动作是"自动执行"，不是"人在系统里点"
□ ⑧ 复核类节点有【不通过 → 判断错误 → 更正（填理由）→ 再复核】闭环
□ ⑨ 一页节点数 ≤32（6 泳道时）或 ≤36（≤4 泳道时）
□ ⑩ 一页泳道数 ≤6（QA/QC、执行/复核不得合并）
□ ⑪ 没有"同一动作画了两遍"（重复出现=该提子流程）
□ ⑫ 图与流程说明表一一对应（跑 audit_fig_table.py 双向 diff = 0 差异）
```

## 三、高频缺陷库（症状 → 病因 → 修法）

| 缺陷 | 症状 | 病因 | 修法 |
|---|---|---|---|
| **悬空分支** | 箭头指向空白 | 异常路径没画终点 | 补终点 或 接回主流程 |
| **无标签判断** | 菱形出两条线没字 | 赶工 | 补 是/否（贴菱形右侧） |
| **一框多动作** | "扫码并核对并提交" | 想省节点 | 拆成 N 个框 |
| **角色错位** | 采购动作画在仓库泳道 | 按常识猜未读文档 | 回原文找操作角色 |
| **功能化** | "点击提交按钮" | 以产品为中心 | 改成"收货员提交收货" |
| **颜色混乱** | 同类动作 3 种颜色 | 无配色规则 | 回归 白/蓝/灰 三色 |
| **编号断号** | 10、20、40 | 删节点没重排 | 压缩行号 + 重排编号 |
| **死循环** | 退回没有出口 | 只画了"退回" | 加"退回 N 次 → 升级主管" |
| **相切/重叠** | 菱形贴着下一行矩形 | 行距 < 元素高 + 8px | `node_h = pitch-8` |
| **文字溢出** | 字出框/压在框线上 | 字号与框宽不匹配 | 缩短文案 或 加宽 或 `lineHeight=0.88` |
| **标签压字** | "是/否"压在菱形里 | 标签挂在线中点 | 标签移到菱形右侧 `offset x=66` |
| **图↔表不一致** | 评审指出"图上没有这一步" | 图改了表没改 | 跑 `audit_fig_table.py` |

## 四、质量提升的四级练习阶梯

| 阶梯 | 练什么 | 素材 | 达标标志 |
|---|---|---|---|
| **L1 临摹** | 抄结构，求形似 | 公司标准模板任选 3 页 | 配色/编号/泳道/连线一模一样 |
| **L2 还原** | 文字 → 图 | 客户 SOP、岗位职责、URS 条目 | 原作者看完说"没漏" |
| **L3 原创** | 听口述当场画 | 会上听一段描述 | 能画出 2 层异常分支 |
| **L4 压力测试** | 找人挑错 | QA/PM 挑错，记录被打回的点 | 被挑出问题从 10 个降到 ≤3 |

⭐ 大多数人 L1 没做够就直接 L3 → 出来"像图但不可用"。**L1 至少 10 页**才有肌肉记忆。

## 五、每张图的五步法

```
① 定边界   起点/终点是什么（不定边界必失控）
② 列角色   先画泳道（部门·岗位），不画框
③ 列动作   用文字列清单"谁 + 动词 + 对象"，先不落框
④ 连判定   补是/否，每个判定只许两个出口
⑤ 三遍查   ①MECE 有没有漏 ②每条线有标签 ③每个分叉有终点
```

⭐ 第③步是关键：**先写字、后画框**。直接拖框的人画到一半必返工。

## 六、八个立竿见影的技巧

```
① 一框一动作            ⑤ 泳道 ≤6 条
② 判定只许两出口        ⑥ 一页节点 ≤32（6泳道）
③ 每个分叉必有终点      ⑦ 配色只表达三件事（人工/系统/线下）
④ 编号步长 10 或 5      ⑧ 同一动作只画一次（重复→提子流程）
```

## 七、一个通用验收问句

> **"如果明天来了个新人，拿着这张图能不能独立把这活干完？"**
> 不能 → 缺的就是要补的。

配套习惯：**画完立刻找一个人看 30 秒**，问"你看得懂第一步该干什么吗？"—— 听不懂的地方是图的问题，不是他的问题。

## 八、素材来源（不愁没东西练）

```
① 公司模板 37 页            → 临摹（L1）
② 客户 URS 每条需求          → 反推该建什么流程（L2）
③ 现有 SOP / 岗位职责        → 还原成图（L2）
④ 自己写的验证方案           → 文字流程变图（L2→L3）
⑤ 日常生活（点外卖/看病/机场安检）→ 练抽象能力，成本为零（L3）
⑥ 同事的图                  → 挑错练习（L4，进步最快）
```

⭐ 第⑤条别小看：用"机场安检"练图比用工作流程效果好——因为简单，能专注**结构**而不是**业务**。
