# 交付、格式转换与 MCP 真连接

> 从 SKILL.md 下沉（2026-10-28 瘦身重构）。原属 garlic-drawio-flowchart-authoring。

```
我生成 .drawio
  → 用户用 app.diagrams.net（在线）或 draw.io Desktop 打开、编辑
  → 交付客户：导出 PNG / PDF / SVG
  → 要亿图格式：draw.io 导出 VSDX → 亿图「导入 Visio」→ 可编辑 .eddx
  → 要进 Obsidian：Mermaid 代码块（能直接渲染）
```

⚠️ 微信/聊天工具发 `.drawio` 前先确认对方能收到（非常见扩展名易被拦），必要时打 zip 或走 file-exchange。

### ⭐⭐ 对方用亿图（万兴图示）画图时：导出要清晰就【优先矢量】

用户会问：**"在万兴图示里面提取出流程图怎么保证清晰度？"**（图要插进 Word 蓝图文档 / 发客户评审）

```
⭐ 清晰度排序：EMF / SVG（矢量·无限缩放）＞ PDF（矢量·打印用）＞＞ PNG/JPG（位图·放大必糊）

路径：文件 → 导出与发送 → 其他格式 → ⭐ SVG / EMF
     文件 → 导出与发送 → PDF（选"矢量/高质量"，别选"压缩"）
     文件 → 导出与发送 → 图片 → PNG/JPG（要位图时把 DPI 拉到 300~600 或放大 2~4 倍）
     文件 → 另存为 → 选格式（菜单名随版本略有差异·两处都找）
```

**按用途选**：插 Word 选 ⭐ EMF（Word 原生矢量·可取消组合微调）；跨平台/网页选 SVG；
打印/评审选 PDF；微信发图看才用 PNG（≥300dpi 且不放大）。

⚠️ 6 个必看坑：

```
① 别用截图 —— 截图 = 屏幕分辨率·插进文档必然模糊
② ⭐⭐ Word 会自动压缩图片 → 文件→选项→高级→勾【不压缩文件中的图像】
   （否则多清晰导进去都被压到 ~220ppi）
③ 导出前：先"适应页面"（防内容被裁）+ 隐藏 网格/参考线/连接点/搜索高亮
④ 图很大时：PNG 用【放大倍数】导出，不是改画布尺寸
⑤ 多页文件：勾"导出全部页面"（否则只导当前页）
⑥ ⭐ .eddx 是私有格式 → 我能提【文字 + 几何】，但提不出矢量图
   ⇒ 矢量导出只能在亿图里做；要高清位图就让他导 PDF 发我
```

⭐ 服务器侧能接的活（比让他在亿图里调参数省事）：他导 PDF 发来 → 我用
`pdftoppm -r 600` / pymupdf 渲成任意 DPI 的 PNG、转 SVG、拼多页、裁白边、批量处理。

⭐ ⚠️ **`.drawio` 不要放进 Obsidian 笔记库**（用户明确纠正过：**「流程图不要放进库里面」**）。
本次先放了 6 个 drawio 到 `20_领域/…/本公司工作/流程图/`，随后被要求撤掉。

```
库（Obsidian Vault）  = 只收 .md（保持纯笔记·轻量同步到手机）
file-exchange        = 图 / zip / 截图包（<交付目录> ↔ 笔记本 E:\file-exchange\）
```

- 交付时一律：`cp *.drawio <交付目录>`，微信只发文件
- 库里若要留线索，只写一节「文件位置」指路（文件名清单 + 存放路径），不放原件
- ⭐ 同类：演示截图包、模板压缩包、培训材料原件同样走 file-exchange，不进库
- ⭐ 顺手清理：每次改名/重生成后，把 file-exchange 里的**旧版/旧命名副本清掉**
  ⭐⭐ 更稳的做法（2026-10-19 实测·本次堆了 11 个版本）：**挪进 `归档-<主题>历史版/` 子目录，不要 rm**
  —— 目录里只留「当前版 .drawio + 当前版 zip」，用户打开文件夹时不会点错旧版；
  旧版还在，他哪天说「还是上一版好」能立刻捞回来
  ⚠️ 别误伤同目录里名字相近的**另一套图**（本次 1.2/1.3/1.4 是另一批，不能一起归档）
