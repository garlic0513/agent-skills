# 接手别人的 .drawio：一致性体检 + 修复（2026-10-22 实测）

场景：用户/同事发来一版图（本项目 40 页，由公司架构团队标准 37 页 + 我们 4 个公共子流程合并而成），
说「按这一版写说明」「把这些问题修掉」。**先体检，再修，最后真渲染复验**——不要边看边改。

## 一、体检七项（跑一遍就知道这版能不能用）

```python
import sys; sys.path.insert(0,'.')
from verify_pages import models      # 兼容压缩/未压缩的 mxfile
P = models(path)                     # [(页名, mxGraphModel), ...]
```

| # | 查什么 | 判据 / 症状 |
|:-:|---|---|
| 1 | **断链** | `<mxCell edge="1">` 里 `source` 或 `target` 为空 → draw.io 允许"松散线"，通常是删节点后留下的残线；表现为流程**从 A 直接跳到 C**，中间步骤缺失 |
| 2 | **重号** | 同页两个节点都是 `20 XXX`（合并两版时常发生） |
| 3 | **重名泳道** | 同页两条同名 swimlane 叠在一起（复制粘贴残留），渲染看不出，但节点归属会错 |
| 4 | **页标题没改** | 复制某页只改了内容没改标题（本次页 10 标题仍是「其他入库主流程」） |
| 5 | **语义重复节点** | 如「156 创建质检单 / 157 生成质检单」——动作其实是同一个 |
| 6 | **编号体系混用** | 01/05（外部系统前置步）与 10/20 并存 —— 常是有意的，**先问再动** |
| 7 | **节点数与说明对不上** | 交文档前拿图的节点数核对说明里的行数 |

⭐ 第 1 项最值钱：本次发现「成品入库」页 **100 之后整段断链**（缺创建质检单/质检子流程/复核 三个节点），
图上却有一条从 100 指向「复核通过？」的松散线。人眼看图只觉得"跳了一下"，程序一查就露。

```python
# 断链快查
for c in m.iter('mxCell'):
    if c.get('edge')=='1' and (not c.get('source') or not c.get('target')):
        print('松散线:', c.get('id'), c.get('source'), '->', c.get('target'))
```

## 二、改 XML 的两个硬坑

```
⚠️ 坑 1：cells 的父是 <mxGraphModel><root>，不是 mxGraphModel
   m = diagram.find('mxGraphModel')
   m.remove(cell)            → ValueError: list.remove(x): x not in list
   ✅ rootEl = m.find('root'); rootEl.remove(cell); rootEl.append(new_cell)

⚠️ 坑 2：改名别做局部替换
   value 里常被 draw.io 包成 <div><span style="...">10 创建采购计划</span></div>
   → 只替换数字会留下脏 HTML。⭐ 命中即整串替换成纯文本（顺手清干净）
```

## 三、改名（最安全的一类修复）

```python
REN = {页序号: [(旧值片段, 新值)]}
for idx, reps in REN.items():
    for c in cells(页[idx]):
        v = c.get('value') or ''
        for a,b in reps:
            if a in v:
                c.set('value', b); break     # 整串替换，保留原 style/id/几何
```

适合：重号、语义重复、语义不清（「120 取消收货？」→「120 是否需要取消收货？」/
「190 取消收货」→「190 执行取消收货」）。
⭐ 只改文案不动几何 = 零风险，优先用这类手段消化问题。

## 四、补节点 + 补连线（几何要对齐现有行距）

```python
# ① 样式别自己写，从同页同类型节点复制
st_rect = 现有系统矩形.get('style')
st_proc = 现有子流程.get('style')
st_tag  = 现有 WMS 小标签.get('style')
st_edge = 现有普通线.get('style')

# ② 坐标：先量出现有行距（本项目 112px），插到空行上，别挤
mk('new-120','120 创建质检单', st_rect, x, y, 100, 65)
mk('new-120t','WMS', st_tag, x+62, y-13, 38, 21)      # 小标签贴右上角

# ③ 连线：source/target 用 id，几何 relative=1
mke('new-e1','100的id','new-120')
```

⭐ 补完必须重算：**新节点所在行的 y 不能与相邻节点重叠**（行距 112、节点高 65/60/80）。
⭐ 删掉的松散边要一起清（否则新旧两条线并存，看着像分叉）。

## 五、复验（三步，缺一不可）

```
① 再跑一遍体检脚本：断链 0 / 重号 0 / 重名泳道 0
② 真渲染该页（webapp + viewer.min.js + chromium 截图）→ 用眼睛确认补的节点接上了
③ 打开文档核对：说明里的步骤号与图上完全一致（补了 120/130/140 就要在表里加三行）
```
