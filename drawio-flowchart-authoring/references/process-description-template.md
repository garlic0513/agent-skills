# 4.x.3 流程说明 · 模板规格与仿写参考

> 用途：用户说「参考下面这段作为模板进行仿写」/「捋一下流程说明」时，照本篇的规格写，
> 不用每次重新问他格式。⭐ 图和说明是同一交付物的两半，编号必须互相对得上。

---

## 一、用户模板的 7 条风格（提炼自他给的原版）

```
① 主步骤 = 「1.」「2.」「3.」平铺，不缩进、不加粗
② 子步骤用点号展开：6.1 / 8.1.1 / 8.1.1.1（层级靠点号，不靠缩进）
③ ⭐ 判定写法固定："X.1 不符合…，执行序号7拒收货物" / "X.2 符合…，执行序号11初检登记完成"
   → 两条分支都必须写"下一步去哪"，不能只写"是/否"
④ 字段与界面项清单用 ①②③ 罗列（不用 - 或 *）
⑤ 界面按钮单独起行：`【收货确认】按钮逻辑`，下面逐条写规则
⑥ 结尾固定："…，流程结束"
⑦ 编号与流程图节点号完全一致
```

## 二、结构骨架（照抄）

```
4.x   流程名称
4.x.1 内容概述
      业务范围：包含哪些业务、单据类型有哪些
      涉及系统：ERP / WMS-WEB / WMS-RF / …（无接口就写"手工"）
      ⭐ 不适用说明：客户没有的设备/系统，写一句"已删除 AGV/WCS 相关步骤"
4.x.2 流程图
      （图）
4.x.3 流程说明
      1.…
      2.…
      3.…
      3.1 …
      3.1.1 …
      …
      【按钮名】按钮逻辑
      规则一
      规则二
      N.…，流程结束
```

## 三、判定分支的标准写法（最容易写歪的地方）

```
✓ 6.仓库收货人员查看外观是否符合收货要求
  6.1 不符合收货要求，执行序号7拒收货物
  6.2 符合收货要求，执行序号8初检登记

✓ 8.1 是否供应商管理（根据物料主数据维护的是否供应商管理判断）
  8.1.1 是，校验当前收货供应商是否存在合格、已批准供应商记录
  8.1.1.1 否，RF端报错提示"非合格供应商或非已批准供应商，不允许收货"，
          后续供应商重新送货或关闭ASN单
  8.1.1.2 是，执行序号9
  8.1.2 否，不是供应商管理的物料，直接执行序号9
```

⭐ 三个要点：
1. 判定节点先写清**判断依据的来源**（"根据物料主数据维护的 xx 字段判断"）
2. 分支用 `X.1 / X.2`，并**明示跳转到哪个序号**
3. ⭐ **终止型节点必须给归宿**（拒收/报错 → "后续供应商重新送货 或 关闭ASN单"），
   否则等于流程断头

## 四、字段清单的标准写法

```
9.1 初检登记信息按物料类型分别维护检查项：
【原辅料】
①是否有中文标签（适用于进口物料）
②是否有进口药品通关单（适用于进口原料）
③是否有厂家检验报告（如果为合格供应商管理，必须上传厂家报告）
④外包装是否完整和密封
⑤运输是否满足贮存条件（增加提示，显示物料管理页面维护的储存条件）
⑥生产日期 ⑦生产日期是否符合要求 ⑧是否让步收货 ⑨厂家批次号
⑩到货数量 ⑪到货温度（按主数据是否需要温度记录判断，需要则为必填）
⑫异常情况描述
```

⭐ 同类物料要**分组写**（原辅料 / 内包材 / 外包材），每组检查项不同；
⭐ 依赖主数据的字段要写明"按 xx 字段判断"，这是后面配系统的依据。

## 五、⭐ 按图捋说明的检查清单（产出"待理顺"表）

| # | 检查 | 典型问题 |
|:-:|------|---------|
| 1 | 图上有、说明里缺 | 漏步骤 |
| 2 | 判定只有一边写了去向 | "否"分支没写去哪 |
| 3 | ⭐ 终止型节点无去向 | 拒收/报错框在图上是死头 |
| 4 | ⭐ 并行 vs 串行没讲清 | 同一节点横竖各引一条线时 |
| 5 | 关键状态未出现 | 库存状态默认值（待检/合格）全篇没写 |
| 6 | 子流程未引用 | 双层框（上架/质检）没写"详见 4.x" |
| 7 | 更新动作不全 | 只写"更新库存"，漏"更新 ASN 单状态" |

回话格式：说明正文 + `⚠️ 按图捋出的 N 处待理顺`（位置 / 问题 / 建议）。

## 六、去模板化三处（抄来的说明必查）

```
① 删不适用步骤：模板带 AGV/WCS/立库 而客户没有 → 整段删
② 去品牌残留：别家 WMS 前缀、"货主是否为 XX"、别家货主代号清单
③ ⭐ 可疑项就地标 ⚠️ 待确认，不臆断：
   库存状态默认值 / 批号规则 / 要不要请验 / 接口是否打通 / 危险品是否纳入
   → 写成"⚠️ 待确认（A…／B…，建议…）"，会上一次问掉
```
