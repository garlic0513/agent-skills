### 九·补、⭐⭐⭐ 用户 2026-10-16 追加的三条硬规则（作图默认带）

用户原话：*"你在画流程图画节点的时候，先确认节点所在的泳道，然后把节点按逻辑在各自泳道自上而下进行排序，
最后再进行连线"* ＋ *"分支节点尽量选左右，进程节点尽量选上下 …… 一定要注意，连接线之间不要重叠或重合"*。

```
【规则 A · 绘图顺序】先泳道 → 泳道内按逻辑自上而下排 → 最后连线
  ⭐ 实现：nodes 里每个节点写成 (id, lane, text, type, 泳道内序号 order)
     y 坐标 = 泳道顶 + 60 + order*vgap（vgap≈110~112）
     → 自动保证"同一泳道内自上而下 = 该岗位的作业顺序"
  ⭐ 好处：每个泳道竖着读就是该岗位的作业清单；跨泳道连线自然呈阶梯状
  ⭐ 回话要点：把每个泳道的清单列出来（"WMS-RF(15)：8 → 8.1 → 8.1.1 → …"）
     用户一眼就能核对泳道归属和顺序

【规则 B · 锚点按节点类型分】
  菱形（decision / confirm 待确认判定）→ 出口优先【左 / 右】
  矩形（process 进程节点）           → 出口优先【上 / 下】（泳道内主干垂直走）
  跨泳道连线                          → 按目标相对位置用左/右
  ⭐ 菱形别用上下口做分支（会压住正下方的节点）；用左右向两侧展开
  ⭐ 自查：统计菱形节点的出口角，若出现 ⬆/⬇ 就要改（"否/B 跳过"类分支也走左右绕行）

【规则 C · 连线禁重叠/禁重合（全局通道表）】
  不要"每条线自己算中点"——多条线会落在同一条 x（或 y）上而重合。
  ⭐ 正解 = 全局 Router，为每条线的中间通道分配【唯一坐标】，冲突则 ±22px 递进偏移：

    class Router:
        def __init__(self):
            self.used_h = set(); self.used_v = set()      # 已用通道
        def take_h(self, key, base, gap=22):
            x = int(round(base)); k = 0
            while x in self.used_h:
                k += 1
                x = int(round(base + (k*gap if k % 2 else -k*gap)))
            self.used_h.add(x); return x                  # 水平段 midx
        def take_v(self, key, base, gap=22):              # 垂直段 midy，同理
            y = int(round(base)); k = 0
            while y in self.used_v:
                k += 1
                y = int(round(base + (k*gap if k % 2 else -k*gap)))
            self.used_v.add(y); return y

  ⚠️ 早期版本按 (源泳道→目标泳道) 分组去重 —— 不够！不同组的通道仍会撞上，
     必须【全局】去重（一个 set 管所有水平通道，另一个管所有垂直通道）。
```

  ⭐ 该 y 落在矩形(高54)/菱形(高78)与行高134的空隙交集里 → 任何泳道任何行都不占这个高度
  ⚠️ 别用"两节点中点"当水平带：不同泳道行号不同，那个 y 在中间泳道可能正好是节点行 → 必穿框

【铁律 2 · 垂直行走 → 只走「泳道间走廊」】
  泳道间距 110px；走廊 = 泳道之间的空白带
  ⚠️⚠️ 走廊做防重合偏移时【必须夹紧在走廊区间 [lo,hi] 内】，
     否则 slotting 一偏 ±40px 就落进相邻泳道内部 → 竖线穿框（本次踩过）

  ⭐⭐ 例外（2026-10-19 起【公司模板风格】必须照这条）：用户要求泳道**紧贴**、不要走廊
     → CORR=0，此时垂直行走只能靠【行间隙阶梯】：
       出源上/下边 → 行间隙横穿 → 进目标上/下边（见 §十三·补2 ⑥）
     → 「铁律 2」只适用于\"泳道之间刻意留了走廊\"的自定义布局（§十八 早期版本）

【三分支路由】
  ① 同泳道+相邻行+x接近      → 直接上下（无 waypoints，最干净）
  ② 同泳道+跳过中间行        → 绕【本泳道外侧走廊】走（"跳过分支"是穿框高发区）
  ③ 跨泳道                  → 源侧走廊 + 目标侧走廊，中间用铁律1的全局行间隙横向穿越

def row_gap_y(oa, ob):          # 铁律 1

def gap_range(lane, side):      # 铁律 2（走廊区间·偏移不得越界）
    if side == "R":
        lo = LX[lane] + lanes[lane][1] + 12
        hi = LX[lane+1] - 12 if lane+1 < len(LX) else lo + 60
    else:
        hi = LX[lane] - 12
        lo = LX[lane-1] + lanes[lane-1][1] + 12 if lane-1 >= 0 else hi - 60
    if hi <= lo: lo, hi = hi - 40, hi
    return lo, hi, (lo + hi) / 2
