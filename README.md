# Agent Skills

个人 Agent 技能集合（Hermes / Claude Code 兼容——遵循 [Agent Skills Spec](https://agentskills.io/specification)）。

## 技能列表

| 技能 | 说明 |
|------|------|
| [cognition-framework-method](cognition-framework-method/) | 认知框架法——「在提出疑惑之前，要表达疑惑」——觉察已知（grill-me 拷问）× 觉察未知（先行组织者框架）→ 精准提问/求助。设备现场认知/OQ/PQ/模糊任务/学习新领域通用。 |

## 安装

将技能目录放入 agent 的 skills 目录（如 `~/.hermes/skills/` 或 `.claude/skills/`）。
