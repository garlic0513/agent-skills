# 需求调研四维记录法 · Research 4D Method

> **把对方口头说的需求，翻译成可执行的需求，并标出还没定的部分。**

## 是什么

一个用于**需求调研**的记录框架，四个维度按固定顺序推进：

```
现状 AS-IS → 目标 TO-BE → 差异 GAP → 待确认 OPEN
（现在怎么干） （想怎么干）  （能不能干） （还缺什么·谁定）
```

**顺序不能颠倒：**

- 没有「现状」就谈「目标」→ 对方讲理想，落不了地
- 没有「目标」就谈「差异」→ 变成推销标准产品，对方反感
- 没有「差异」就谈「待确认」→ 清单全是废话，没有决策点

## 核心亮点

- ⭐ **每个维度配「追问清单」**——现场照着问，问出真话
  - 现状：「能不能给我看一下现在用的表？」
  - 目标：「如果只能实现一个，你先要哪个？」
  - 差异：「如果标准做法是另一种，能接受吗？」
  - 待确认：「拖着不定会卡住什么？」
- ⭐ **差异必须三选一**：`能（标准）` / `部分（需配置）` / `不能（需定制）`——这是报价与工期的依据
- ⭐ **待确认必须带责任人 + 期限**——否则永远是「待确认」
- ⭐ **会后自动出三张清单**：需求清单 / 选项清单 / 风险清单

## 什么时候用

- 需求调研会、客户访谈、现场走访
- 解读需求文档 / URS / 招标文件
- 梳理现有业务流程、找痛点
- 需要产出「待确认清单」推动对方决策
