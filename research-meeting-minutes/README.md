# 会议纪要写法 · Meeting Minutes That Work

> **纪要的目的不是「记录」，而是【决策留痕 + 行动落地 + 事后可查】。**

## 核心认知

一份纪要写得漂亮不重要，**可执行 + 可追溯**才重要。

## ⭐ 高质量纪要 6 条标准

| # | 标准 |
|:-:|------|
| 1 | ⭐ 每个议题必须有**结论**（同意 / 不同意 / 待定）——禁止只写「讨论了 X」 |
| 2 | ⭐ 每个待办有**责任人 + 期限 + 交付物** |
| 3 | ⭐ 区分四类内容：事实 / 观点 / 决策 / 待办 |
| 4 | ⭐ 保留对方**关键原话**（加引号） |
| 5 | ⭐ **当场复述 / 24h 内确认**——有效性靠双方确认，不靠文笔 |
| 6 | ⭐ **可追溯**：编号·日期·参会人·议题号·引用的文档版本号 |

## 四不写

```
✗ 流水账（按谁先说话的顺序记）
✗ 没结论的讨论（要么给结论，要么进待确认清单）
✗ 主观评价
✗ 把推断当事实写（标「推断」+ 依据）
```

## 结构（8 段）

```
基本信息 → 会议目的与议题 → 各议题记录（讨论要点/原话/结论）
→ 决议事项 → 行动项 → 待确认项 → 附件与材料清单（带版本号） → 下次安排
```

## 什么时候用

- 会后出纪要（尤其是需求调研会、客户会、项目例会）
- 判断一份纪要质量够不够
- 整理行动项 / 待确认事项
